Projeto de Análise de Sistemas : Mobilidade assistida por voluntários para consultas

Desenvolvimento de uma Plataforma Digital de Gestão Integrada de Mobilidade Assistida para conectar utentes (idosos ou pessoas com mobilidade reduzida) a voluntários e frotas adaptadas para transporte e acompanhamento em consultas médicas. 

Promotor: Instituição Particular de Solidariedade Social (IPSS)

Âmbito: Aplicação móvel para voluntários, portal web para coordenação e IPSS parceiras (ex.: lares de idosos agendarem viagens), e canal assistido/telefónico para utentes.
